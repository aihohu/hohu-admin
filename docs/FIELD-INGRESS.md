# 字段权限入口与兼容边界

本文适用于 Backend/Web 0.2.0 候选。角色业务字段权限、专用安全动作、固定运行协议分别执行各自契约；入口登记不会授予权限，也不代表部署已获得激活资格。

## 登记和实际授权

应用启动在进程准入、数据库及 Redis 初始化前检查[固定入口声明](../app/core/field_ingress_manifest.py)。声明精确绑定 HTTP 方法、路径、handler 和静态挂载实现，并区分 AI 开启与关闭状态。未知路由、替换 handler、重复接线或不符合发布规则的静态目录拒绝启动，错误为 `FIELD_INGRESS_UNDECLARED`；登记预算超限为 `FIELD_INGRESS_LIMIT`。该检查不推断路径前缀权限，不提供 legacy 回退，后续请求仍由真实事务所有者检查当前身份、租户、功能、记录范围、字段用途及来源。

工具与任务注册同样不授予执行身份。AI 工具使用代码目录及完整事务计划，未知工具不执行；任务必须满足已登记 TaskSpec、闭合参数模型与服务协议，普通旧函数登记不能自行成为可调度能力。未挂入主应用的模块不因存在源码获得外部入口。

## 固定协议的允许范围

| 入口 | 来源与返回范围 | 授权边界 |
| --- | --- | --- |
| 登录、refresh、logout、自助注册与恢复 | 既有 JWT、一次性证明及固定状态 | 服务端定位租户、重验当前身份；密码和证明仅作输入，不作为字段授予 |
| `getUserInfo` | 固定 `userId`、`userName`、`roles`、`buttons`、`isSystemAdmin`；头像单独投影 | 身份锚点不同于管理用户 DTO；本人资料遵守既有 own-account 用途和跨对象来源规则 |
| `getUserRoutes`、`isRouteExist` | 当前用户实际可见运行树及其名称布尔判断 | 同一租户、当前角色/菜单与状态；不可用存在性查询探测未授权、禁用或孤儿菜单；菜单管理仍要求独立功能与字段权限 |
| 常量路由、登录选项 | 代码所有的常量及租户定位配置 | 不读取业务对象副本 |
| `/auth/capabilities` | 精确四键 `registrationEnabled`、`passwordResetEnabled`、`emailEnabled`、`codeMinutes` | 公开 locator 在 G/B 共享屏障内复核；只投影三项设置和全局邮件就绪状态；提示不替代注册/重置的写授权 |
| 公开品牌、协议、runtime、公开配置 | 固定设置白名单，或当前明确发布且来源吻合的配置值 | 任意角色字段 grant 不能将秘密公开；撤回、状态、租户及来源仍需复核 |
| 公开图片 | 当前明确公开的资源及受限历史头像/品牌引用 | `/uploads` 必须使用发布回调与正确公开根；私有内容、表格和错误文件不能静态交付 |
| health、metrics、框架文档 | 固定健康状态、有限标签统计、接口描述 | metrics 未知标签归并 `unknown`，不回显工具原输入、用户或凭据；响应上限 8 MiB，超限固定 503；成功与失败均 no-store。抓取网络继续由部署配置控制 |

导航最多读取 8192 个菜单及一个超限哨兵、深度最多 16；存在性判断遍历已授权树，不追加管理菜单查询。公开账号能力沿用 8 秒只读事务预算并在返回前确认回滚，不读取或解密 SMTP 密码。诊断输出检查是已生成响应的逻辑上限，不是进程内存硬限制。

## 客户端、安装与恢复兼容

| 既有入口或产物 | 当前处理 |
| --- | --- |
| 旧 Web 全量 PUT、无版本 Header、伪造版本 Header | 服务端按全部实际携带字段检查，原值也需写权限；Header 不提供授权。新 Web 按实际修改提交 PATCH，关系不完整时禁止回写 |
| 旧用户字段策略 API | 保留明确旧 wire、版本和 CAS 约束；通用策略激活冲突不降级为旧策略放行 |
| 旧目录和新用途 | 已发布目录摘要保持不可变；新增用途不默认授予。策略未配置时按当前 legacy/ready/enforcing/frozen 状态处理，不把空规则解释为全部允许 |
| 导出、模板、导入错误文件、AI 结果和旧链接 | 在当前身份、原 owner、原用途及来源下复验；隐藏列/值按传输契约投影，无来源不能认领或生成新授权；失败不重放已完成或未知写入 |
| 默认租户系统管理员、PlatformPrincipal | 两种身份域分别验证；固定控制摘要不等于租户业务字段全权；目标、原因及审计约束继续生效 |
| 旧 CLI 默认 migrator、旧安装脚本 | 不接受无停写证据的初始化；CLI 0.1.16 按[受控交接](CONTROLLED-INSTALL.md)手工固定产物并跳过默认迁移 |
| 旧迁移起点、旧资格、恢复 | 仅接受受控安装列出的迁移起点；旧资格不能签发当前活动策略。恢复配套数据库、文件、密钥及撤权事实，禁止以降级删除来源或临时补列修复 |
| 直接 all、API 与独立 scheduler、Docker Compose | 使用相同维护证据接口；API 内 AI 恢复/过期任务也必须停写、禁止重入并核验数据库在途事务。Ctrl+C 返回不构成证据 |

业务字段和稀疏 DTO 见[用户投影](USER-FIELD-PROJECTION.md)、[关系对象](RELATION-FIELD-PROJECTION.md)、[配置与任务](CONTROL-FIELD-CONTRACTS.md)、[AI 与后台交付](AI-DELIVERY-FIELDS.md)。策略管理及激活见[管理契约](FIELD-POLICY-MANAGEMENT.md)，部署停写见[授权维护](AUTHORIZATION-MAINTENANCE.md)。最终镜像、CLI、平台及恢复组合仍以正式不可变发布清单为准。
