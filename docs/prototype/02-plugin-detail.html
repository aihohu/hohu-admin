功能介绍

概述

CRM 客户管理套件是一个完整的客户关系管理解决方案，通过低代码配置实现零代码部署。包含客户信息管理、订单跟踪和商品管理三大模块。

功能特性

  • 客户管理 — 完整的客户信息录入、分类管理、等级划分（A/B/C 级）
  • 订单跟踪 — 订单创建与状态流转（待支付 → 已支付 → 已完成），自动关联客户
  • 商品管理 — 商品信息维护，支持多字段自定义
  • 多表关联 — 订单自动关联客户名称，列表页直接展示
  • 数据校验 — 基于 JSON Schema 的表单验证，必填、长度、格式校验

数据模型

插件包含 3 个数据模型：

  • customer — 客户信息（名称、等级、联系方式、备注）
  • order — 订单记录（客户关联、金额、状态）
  • product — 商品信息（名称、价格、库存）

权限说明

本插件声明了以下权限：

  • 菜单注入：注入侧边栏菜单项

低代码插件不执行任意代码，安全性由平台保障。
