# 关系对象读取与字段来源

角色、部门和菜单的管理读取在独立事务中重验当前身份、租户、功能权限、记录范围和策略。分页、详情、树、选择器和授权绑定读取在同一授权屏障内完成输出；事务结束后不再加载业务关系。读取不提交业务变更，也不递增授权 epoch。

## 查询与投影

字段不可读时省略该属性，合法空值仍输出 `null`。角色名称的国际化键随名称权限裁剪。查询权限按用途区分，角色编码、部门显示顺序和菜单显示顺序的隐式排序也需要相应资格。反例证明覆盖原记录范围，在用户筛选、计数和分页前执行；未命中条件不能绕过证明。

用户列表的 `roles`（编码）、`roleNames`、`roleNameKeys` 按真实角色 ID 使用同一稳定顺序。主关系可读而某项来源不可读时，该位置返回 `null`；不压缩数组，不用国际化键恢复隐藏名称。个人资料中的 `roles` 继续表示角色名称。用户的 `deptNames` 只有全部真实部门名称来源均可读时才交付，避免返回误导性的部分聚合。关系的完整替换编辑器必须拒绝不完整集合。

部门负责人依赖内部的同租户用户来源 ID，并同时检查部门负责人字段、真实用户账号/昵称及其独立记录范围。显示当前昵称，空昵称回退账号；查询匹配当前账号或昵称。历史文本无来源 ID 时不作为可信展示或查询结果，也不按同名自动认领；合法清空仍返回 `null`。负责人查询要求原部门范围内来源完整，并检查两对象的查询用途。

用户查询拒绝继续使用 `FIELD_QUERY_DENIED`；角色 Agent 绑定的缺失角色继续使用 `AI_ROLE_NOT_FOUND`。角色摘要、详情和可分配项使用各自的闭集 DTO，不因目录字段增加而扩大公开响应。

树只使用可见节点及允许读取的父关系构造局部根和祖先路径。范围外或不可见的父节点不会恢复到输出中。选择器标签不可读时拒绝整个选择结果，不靠删掉选项伪装完整。用户可分配角色沿用 `system:user:role-auth`，不要求额外的角色列表按钮权限。

## 运行导航与管理入口

动态运行导航是当前身份的固定最小协议，与菜单管理 DTO 分开。它在当前屏障内重读角色及启用菜单；固定平台页面仍仅供系统管理员。普通路由存在性查询需要 `system:menu:list` 和 `route_name` 的精确查询资格。

字段策略管理的业务标题也遵循角色字段读取。当策略不可用、目录尚未包含关系对象或处于受控准备过程时，可保留固定角色 ID 作为修复锚点，不返回未经证明的名称、编码或数据范围。

## 限制

普通读取总时限为 8 秒，单次锁等待不超过 2 秒、单条语句不超过 5 秒；累计最多 4096 次 SELECT、100000 个物化行、64 MiB 解码估算。分页最多 100 行；角色全集最多 4096 项，部门和菜单最多 8192 项；树最多 16 层。来源批次最多 256 项，累计最多 16384 条引用及 4 MiB 规范数据。超限拒绝，不静默截断。这些限额不构成容量或延迟保证。

当前受控准备目录包含用户、字典类型、字典项、数据范围演示、角色、部门和菜单七个对象。目录注册和适配器实现不等于取得七对象生产激活资格；完整交付与恢复资格仍需满足。导入、导出、AI 交付等入口不能凭关系读取适配器获得额外权限。

## 编辑快照与能力提示

`GET /system/{role,dept,menu}/form-context` 接受 `mode=create|update`。修改必须提供规范十进制字符串 `recordId`；新增不接受记录 ID，可提供 `parentId`（根为 `"0"`）。未知参数、前导零或超出有符号 BigInteger 的 ID 拒绝。快照包含 `record` 和 `fieldPolicy`，在同一 G/B 保护期内核验当前身份、真实目标、字段与来源，输出后回滚。

`fieldPolicy` 包含目录字段名的 `read`、`query`、`create`、`update` 数组、`readLevels`（plain/masked/hidden）、`specialCreate`、`specialUpdate`、`canCreate` 和完整集合标记 `complete`。列表与部门 tree-list 同时提供页面能力及记录能力。这些仅供当前界面呈现，后续写入必须重新授权。角色和部门新增/修改能力匹配 System 写者的显式功能权限；读取或导航的超级角色规则不能替代该写入检查。菜单配置遵循其配置写者的功能权限规则。

Web 从当前快照编辑，仅发送显式修改且允许写入的字段；缺失不补默认值，合法 `null` 保留。只写字段与可修改的脱敏字段使用空的替换草稿，不把隐藏值或掩码回填为原值。角色编码不可修改；状态、数据范围、部门父关系、菜单注册等专用协议继续使用原有委派、完整锁计划及最后管理入口检查，不变成普通字段许可。

菜单子按钮必须完整可读才提供替换草稿，每批最多 256 项、总数最多 8192 项；隐藏一项或标签/编码不完整时省略整个集合并禁止替换。菜单与 Agent 授权选择器遇到加载失败或未知选项不能提交。部门成员页返回字符串 `authorizationEpoch`；Web 仅在全部页的 epoch、总数、唯一 ID 及替换来源均一致时开放完整集合编辑，切换目标或关闭后不接收旧响应。不同页不宣称共享同一次数据库锁期。

关系读取另设阶段 SELECT 上限：barrier 64、identity 128、manifest 1030、scope 1024、proof 256、projection 256、source 66、delegation 1024。总预算持续累计，嵌套 manifest 校验继承当前阶段；超限在下一条 SELECT 发出前拒绝。阶段上限之和不代表总请求可同时达到全部上限。
