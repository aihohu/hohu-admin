# 用户查询与字段输出契约

本文适用于产品与 Backend 0.2.0 开发分支。字段策略尚未开放整体激活：持久化状态与生产入口仍只接受 `legacy` / `ready`，候选规则不会改变用户权限或审计日志显示。不能通过请求参数开启 enforcing。

## 读事务与输出

用户列表、本人资料、认证头像与邮箱、部门成员及租户审计列表在专用读事务中重验身份和原有功能权限。读事务持有全局与租户共享授权屏障，直到查询和 DTO 投影完成；授权写者必须等待该事务释放屏障。

用户 DTO 使用显式字段来源，不返回 ORM 对象图。ID 为字符串；字段不可读时省略键，数据库实际空值保留为 `null`。列表手机号、邮箱继续遵循掩码上限。角色及部门名称、ID 和关系标记随对应关系字段整体投影，不能通过标签绕过字段决定。

`fieldAccess` 只包含能力信息：`read`、`maskId`、`create`、`update`、`replace` 和 `queryOps`。它不携带字段值，也不是写入授权凭据。界面可据此显示操作，但服务端仍重新验证权限。列表元数据受原有功能权限约束；本人账户更新能力仅作用于当前账户。

`GET /system/user/field-capabilities` 返回本人资料的字段能力。认证最小身份继续返回 `userId`、`userName`、`roles`、`buttons`、`isSystemAdmin`；头像单独投影，不将最小身份扩展为任意个人信息查询。

列表固定按创建时间倒序，再按用户 ID 倒序，最多每页 100 条。注册查询计划声明过滤、角色关系条件和固定排序依赖；字段查询证明检查施加客户端过滤和分页前的完整基础记录范围。缺少查询授权时整个请求返回 `FIELD_QUERY_DENIED`，不能先缩小结果或 total 再验证。记录权限仍由服务器按租户和数据范围解析。

## 部分更新

`PATCH /system/user/{user_id}` 使用原 `system:user:edit` 权限及写事务入口：

- 未携带字段保持原值；可空字段显式 `null` 表示清空。
- 用户名和状态允许省略，但不接受显式 `null`；空请求拒绝。
- 未知字段、同一字段同时使用 snake_case 与 camelCase、密码或关系字段混写均拒绝。
- 手机号、邮箱的掩码占位符返回 `FIELD_MASKED_INPUT_INVALID`，必须填写新值或省略。

原 `PUT /system/user/{user_id}` 继续要求用户名和状态。携带的字段即使值未变化，也纳入字段写入检查。密码与完整角色/部门关系替换继续使用各自接口。AI 工具既有 `None` 表示未修改的语义不变。

## 身份副本与开放边界

legacy/ready 审计列表保留原历史用户名和日志事实。内部严格投影适配器按稳定 tenant/user ID 和字段来源检查当前可见性；它没有公开路由或客户端模式开关。严格适配器要求调用者预先取得全局共享屏障与租户独占屏障，阻止审计追加在来源覆盖证明与筛选、计数之间插入新记录；不能在查询途中升级锁。

操作日志的历史用户名可关联到原用户字段，但当前用户缺失或不在可见范围时，严格投影省略副本。登录输入可能是用户名或邮箱，只有 user ID 无法证明其字段来源；自由文本参数和消息也没有逐字段来源，严格投影整体省略这些值，不按文本猜测身份。历史数据库事实不被改写。

AI 历史与上下文、其他复制来源和 Web 完整交互尚未完成统一字段策略适配。当前兼容入口会拒绝已激活或不可逆的策略状态；完成全入口适配和整体验收前，不开放租户策略激活。

## 导入、导出与文件下载

导入解析保留实际提供的列，拒绝未知表头和重复别名；空列不会当作未提供。导入前声明用户名与工号匹配、携带字段、默认性别/状态及角色/部门关系写入要求，整批检查在创建持久预览或执行首行写入之前完成。覆盖仍保留既有语义：空资料不清空，性别和状态采用默认值；员工同步模式和冲突策略在预览后不能更改。改变模式后应重新预览。

导出最多5000行，固定按用户ID排序，查询证明先于筛选和行数限制。字段投影取export与management.read的交集；脱敏值进入工作簿，全部不可见的列省略，部分不可见的单元格显示“未授权”。部门路径和角色编码随关系根一起裁剪；用户文本作为Excel文本保存。

新文件保存独立内部字段来源，包括租户、操作人、来源对象、字段等级或写入要求、策略水位、目录/构建版本和文件摘要。元数据接口不返回该来源记录。下载重验当前身份、功能、对象/字段权限、来源水位和文件内容；无法证明时返回`FIELD_TRANSFER_REGENERATE_REQUIRED`，应重新生成。旧无来源资产仅在显式legacy/ready兼容路径保留原下载行为；严格适配器拒绝。文件来源不替代AI执行完成证明和签名下载令牌。

`GET /system/file/import-error/{batch_id}.xlsx` 使用Bearer身份和`system:user:import`权限，仅下载本人批次的错误文件。REST导入和批次详情的`failedRowsFile`返回此地址；文件包含行号、字段、稳定错误码和静态说明，不复制失败原值。预览源有效期10分钟，错误附件为完成后24小时，导出文件30天；响应禁止缓存。

模板、批次/日志、导出任务读取在共享屏障内形成DTO或完整文件。模板部门来自当前可访问范围，角色来自当前可授予范围；隐藏字典也遵循相同约束。普通用户仅能查看本人批次/任务，超管可跨操作人查看。操作人名称依据当前用户ID和字段权限投影；不明来源的日志正文、筛选快照、理由与错误自由文本不返回，文件名统一显示为`users.xlsx`。历史审计事实保持不变。
